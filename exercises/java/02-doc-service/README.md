# Übung Java 02 — doc-service

Ein Dienst zur Dokumentenablage: Dokumente speichern und laden, ZIP-Archive übernehmen,
XML-Begleitdateien auswerten, Bearbeitungsstände sichern und wiederherstellen.

**Aufgabe:** Geht das Projekt wie in einem Code-Review durch — Code, Build und Repository.
Nicht jede auffällige Stelle ist ein Fehler: Notiert auch, was ihr geprüft und für in Ordnung
befunden habt, und warum.

```bash
mvn verify      # übersetzt und führt die Tests aus
```
