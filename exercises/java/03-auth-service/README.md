# Übung Java 03 — auth-service

Ein Dienst rund um Kundenkonten: Token ausstellen und prüfen, Konten anzeigen und schließen,
Partnersysteme anbinden, Felder verschlüsseln.

neben wenigen Fehlern — notiert auch, was ihr geprüft und für in Ordnung befunden habt, und
warum.
