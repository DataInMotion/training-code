# Übung Java 01 — user-api

Ein kleiner Dienst zur Benutzerverwaltung: Benutzer suchen und anzeigen, anmelden, ein
Reset-Token anfordern, neue Benutzer begrüßen.

**Aufgabe:** Geht das Projekt wie in einem Code-Review durch — Code, Build, Konfiguration,
Repository und Pipeline. Nicht jede auffällige Stelle ist ein Fehler: Notiert auch, was ihr
geprüft und für in Ordnung befunden habt, und warum.

```bash
mvn verify      # übersetzt und führt die Tests aus
```

Der Dienst wird in der Übung nicht gestartet; es geht um das Lesen.
